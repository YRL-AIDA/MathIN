В систему загружается 10 документов, выбранные таким образом, что 1-целевой, 4 связанные с ним, 5 не связанные (но схожие по тематике).
Задача стоит в том, чтобы проверить утверждение из целевой статьи, которое ссылается на одну из 4-х связанных работ (указаны могут быть в литературе).

Процесс следующий:
1. Документ переводится в логическую структуру
2. Из регионов выбираются: теоремы, леммы, утверждения, определения, гипотезы, следствия.
3. LLM по каждому региону задается вопрос ("текст ниже является доказательством к этому утверждению?") итерационно, пока не дойдет до следующего утверждения или конца (скажет нет или закончится статья).
4. Далее по тексту доказательства выясняется используется ли в доказательстве та или иная лемма/утверждение/определение (также ориентируется на литературу)
5. Строится граф знаний для данной работы
6. LLM по данному доказательству формирует код lean
7. Проверяется код Lean на компиляцию (опираясь на утверждения из статьи, из работ (которые считаются истинными))



Ожидаемая структура:

Теорема:

```text
theorem_name/
├── lakefile.toml          # Конфигурация сборки проекта
├── lean-toolchain         # Версия Lean
├── TheoremName.lean         # Корневой файл, импортирующий все модули
└── TheoremName/
    ├── Axioms.lean        # Файл с аксиомами из связанных работ
    ├── Target.lean        # Файл с целевой теоремой и её доказательством
    └── Helpers.lean # Вспомогательные леммы
```
