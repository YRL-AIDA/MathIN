# Semantic Search over 9 Million Mathematical Theorems — описание статьи 

## Суть работы

Авторы предлагают инструмент для семантического поиска математических теорем. Они извлекли около 9 миллионов теорем из arXiv и семи других источников, построили для каждой теоремы текстовое описание на естественном языке и организовали поиск по этому описанию. Самое интересное с практической точки зрения — наличие MCP-сервера, позволяющего подключать поиск теорем к ИИ-агентам.

## Проблема

Математическое знание организовано вокруг дискретных результатов: теорем, лемм, предложений и следствий. Однако большинство существующих систем поиска работают на уровне документов (статей целиком), вынуждая пользователя самостоятельно переходить между статьями и искать нужное утверждение вручную. Это важная проблема, потому что результат может быть уже получен кем-то давно, но исследователь об этом просто не знает. Известны случаи, когда ИИ «решал» задачи, которые были решены более 50 лет назад. Аналогично, из 14 000 отозванных препринтов arXiv 2,5% были отозваны именно потому, что результат уже был опубликован ранее.

## Корпус

Корпус собран из:
- arXiv (99,5% теорем)
- Stacks Project
- ProofWiki
- ещё пяти источников (Open Logic Project, CRing Project, Stacks and Moduli, HoTT Book, An Infinitely Large Napkin)

Всего 9,2 миллиона утверждений. Это не только теоремы: больше всего лемм (3,3 млн), теорем — 2,9 млн, предложений — 2,1 млн, следствий — 1,0 млн.

## Основные вклады

1. Сам набор данных — крупнейшая публичная коллекция неформальных математических теорем.
2. Способ представления единицы данных, удобный для LLM: LᴬTᴇX — не лучший вариант для эмбеддингов, поэтому авторы генерируют «слоган» (краткое описание на естественном языке).
3. Поиск работает лучше, чем ChatGPT 5.2 с поиском и Gemini 3 Pro.

## Структура теоремы 

Имя:
- тип (лемма, теорема, предложение, следствие);
- номер;
- примечание.

Тело: LᴬTᴇX-содержимое, в котором раскрыты авторские макросы (например, `\R` заменяется на `\mathbb{R}`).

## Конвейер

Пользователь задаёт вопрос, который индексируется с помощью эмбеддингов (Qwen). По запросу находятся близкие теоремы и следствия. Теорема выделяется вместе с аннотацией статьи, контекстом раздела и телом. Формулы хранятся в виде LᴬTᴇX-разметки. Затем DeepSeek V3 составляет слоган, для которого строится эмбеддинг.

## Парсинг

Используются три подхода:
1. Основной — поиск по узлам plasTeX: документ представляется как дерево.
2. Резервный — собственный LᴬTᴇX-пакет для логирования теорем.
3. Резервный — регулярные выражения по `\begin{}` — `\end{}`.

Для других источников (0,5%) применяется привязка к их структуре; парсер не универсальный, а адаптированный под каждый источник.

## Представление теорем

Теоремы сохраняются в LᴬTᴇX, а описание генерируется с помощью DeepSeek V3. Тестируются три стратегии подачи контекста:
- только тело;
- тело + аннотация;
- тело + введение.

## Поиск 

Используется Qwen3-Embedding-8B, хранение — в PostgreSQL с pgvector и HNSW-индексом. Сначала находятся top-k кандидатов по расстоянию Хэмминга (эмбеддинги записываются в бинарные коды), затем выполняется переранжирование по косинусному сходству.

## Валидация

Верификация проводилась математиками: было отобрано 111 различных запросов. Математики по памяти описывали теоремы, которые они уже читали, не глядя на точную формулировку. Затем они отобрали работы, где эти теоремы могли встречаться. Это использовалось для проверки.

## Метрики 

- Hit@k — среднее число угаданных из k.
- MRR@k — среднее 1/позиция (например, 1/5, если правильный результат на пятом месте).

## Результаты 

- Добавление к LLM RAG с теоремами снижает галлюцинации: Claude без RAG дал уверенный, но неверный ответ, а с RAG — правильный, со ссылками на конкретные теоремы.
- Эксперимент по контексту: лучше всего работает первая секция статьи как контекст.
- Лучше работают закрытые модели (Claude Opus 4.5, Gemini 3 Pro), разница около 10%.
- Размер модели эмбеддингов играет роль: с ростом модели растёт качество.
- Короткие запросы работают плохо, но их можно дублировать несколько раз («Landau equation Landau equation»).
- Показано, что эмбеддинги далёких областей (теория вероятностей и алгебраическая геометрия) далеки, а связанных (теория вероятностей и статистика) — близки.

## Лучший результат  

45,0% Hit@20 на уровне теорем и 56,8% Hit@20 на уровне статей — лучше, чем ChatGPT 5.2 с поиском (19,8%), Gemini 3 Pro (27,0%) и Google Search (37,8% на уровне статей).
